# Divã Virtual 2.0 — protótipo

## Rodar
`npm install` e `npm run dev`.

## Publicar no Netlify
Importe este projeto de um repositório Git. Comando de build: `npm run build`. Diretório de publicação: `dist`.

## Avisos
- O modo de IA local usa WebLLM e requer WebGPU; não funciona em todos os dispositivos.
- O modelo local pode exigir download grande e memória elevada.
- O modo guiado usa respostas por regras; não tem a mesma qualidade de uma IA conversacional.
- A avaliação é **somente demonstrativa** e não deve ser usada para certificação.
- Sem autenticação, banco seguro ou registro oficial nesta versão.
- Para 5.000+ alunos, medir uso e testar franquias de hospedagem antes de liberar amplamente.
- Não inserir dados reais de pacientes.
